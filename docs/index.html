Questions

What chartered accountants ask before the first filing.

Ask on GitHub

What does the AI see?

Line-item names and amounts, only when you ask it to tag or fix. Company name, CIN, PAN, director IDs and the whole workbook never go to it.

Does it need the internet?

Yes. Taxonomy data and the AI come from the XBRL Autopilot server. Your project file stays on your computer.

Where is my work saved?

In one .axbrl project file. Open it again and you carry on where you stopped.

Why does Windows warn on install?

The installer is not code-signed yet. In the SmartScreen box choose More info, then Run anyway.

Which filings can I make?

AOC-4 XBRL under Ind AS 2017 and C&I 2016. Cost audit filing (CRA-4) is planned next.
